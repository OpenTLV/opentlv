# OpenTLV logo

[opentlv.svg](opentlv.svg) is retained for the Core README and offline repository
browsing. The three blocks represent Tag, Length, and Value; the open enclosure
groups them into a TLV element.

The [portal asset sources](https://github.com/OpenTLV/opentlv-docs/tree/main/docs/assets)
own the shared visual design, light/dark variants, site header mark and favicon.
Update the retained README logo when that shared design changes. Assets use the
repository's [MIT license](../../LICENSE).
