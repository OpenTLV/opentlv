# Documentation

The [documentation portal](https://opentlv.github.io/opentlv-docs/) publishes
versioned guides and API references from these Core-owned sources.

Start with the [Core documentation index](index.md) for source links and the
progressive learning path. The portal owns the website homepage and global
navigation; component repositories own their language and tool manuals.

For contributor onboarding, use [Contributing](../CONTRIBUTING.md) and
[the development workflow](development/workflow.md).

Before adding or moving documentation, consult the
[ownership rules and source inventory](development/documentation-ownership.md)
for Core, bindings, tools and the standalone portal.
