# Playground

The browser UI is maintained in the
[OpenTLV documentation portal](https://opentlv.github.io/opentlv-docs/latest/playground/).
Choose the documentation version there to use its selected Core build.

The portal owns the playground page, JavaScript and stylesheet. `opentlv-js` owns the
[WebAssembly implementation, build target and tests](https://github.com/OpenTLV/opentlv-js/blob/main/docs/webassembly.md).
Parsing runs entirely in the browser; input is not uploaded.

The [historical playground](https://opentlv.github.io/opentlv/latest/playground/)
remains available with its archived Core version.
