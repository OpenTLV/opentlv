# Behavioral scenario inventory

Use the named suites below to find the assertions for each Fixed TLV
contract. Parameterized cases run for length widths 1 through 8 in both
byte orders. The [testing guide](testing.md) shows how to select a suite,
an individual case, or a single wire layout with CTest.

| Core scenario | Where it is checked |
| --- | --- |
| Convert zero and the largest representable count to `size_t`. On x86, reject 2³² and `UINT64_MAX`. On x64, convert both exactly. Add through the 64-bit limit, reject overflow and preserve the output on failure. | `CoreSize` in [size_test.cpp](../tests/core/size_test.cpp) |
| Copy a borrowed value, keep the supplied pointer for empty views, reject missing storage and preserve the destination on error, including an unrepresentable size on x86. | `CoreValue` in [value_test.cpp](../tests/core/value_test.cpp) |
| Compare C and C++17 length reads and writes at unaligned addresses for zero, a patterned value and the field maximum. Check literal bytes, counts, sizing queries and preserved outputs for short fields and unencodable lengths. | `FixedLength` in [fixed_length_test.cpp](../tests/core/fixed_length_test.cpp) |
| Reject zero or overwide length fields, unknown byte order and missing arguments. Compare C and C++ outputs for null buffers with zero or positive extents. | `FixedLengthArguments` in [fixed_length_test.cpp](../tests/core/fixed_length_test.cpp) |
| Measure opaque tags, empty and nonempty payloads, and a header or complete element of exactly `SIZE_MAX`. Reject overflow, invalid formats, mismatched tag widths, missing data, and values beyond the wire or native limit. | `FixedMeasurement` and `FixedElementSize` in [fixed_measure_test.cpp](../tests/core/fixed_measure_test.cpp) |
| Compare C and C++ categories and messages for every named result and for unassigned codes. Round-trip a diagnostic with full-width counts. | `CoreResult` in [result_test.cpp](../tests/core/result_test.cpp) and `CppCore.RoundTripsDiagnosticFieldsAndFullWidthCounts` in [cpp_core_test.cpp](../tests/core/cpp_core_test.cpp) |
| Convert borrowed descriptors between C and C++17, keep views alive after the source descriptor goes out of scope, and compare size limits, format validation, wire bytes and failure outputs across both interfaces. | `CppCore` in [cpp_core_test.cpp](../tests/core/cpp_core_test.cpp) and `CppFixed` in [cpp_fixed_test.cpp](../tests/core/cpp_fixed_test.cpp) |

## ABI, fuzz and coverage checks

| Regression risk | Gate and evidence |
| --- | --- |
| A public declaration, record layout or library export changes. | `abi-layout` checks C signatures, enum values, sizes, alignments and member offsets on x86 and x64. The [header probes](../tests/check_public_api.py) compile each header in isolation and check diagnostics. The [package checks](../tests/check_cmake_package.py) build and run C99 and C++17 consumers against build-tree and relocated static and shared libraries, verify installed examples' output and compare symbols with their inventories. [ABI verification](api-abi.md#visibility-and-verification) |
| Unexpected wire bytes or capacities break a C reader or writer contract. | Both libFuzzer targets replay their checked-in inputs before bounded mutation under ASan/UBSan. The reader compares each record with an independent decoder. The writer checks encoded bytes and cursor state against the expected result for the available capacity. A saved failure input can be passed directly to its target. [Fuzz inputs and replay](../tests/fuzz/README.md) |
| A production path loses execution coverage or a public function loses its behavioral check. | The GCC/gcov gate requires 100% of reachable lines and branch outcomes. Every public function must execute and its mapped behavioral test must pass. CI compares two fresh reports byte for byte. The two reviewed branch exclusions concern states rejected by cursor initialization. [Coverage thresholds and exclusions](coverage.md) |
