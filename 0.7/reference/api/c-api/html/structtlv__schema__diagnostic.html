Detailed Description

Common failure diagnostic paired with one discriminated typed detail.

Shared by validation and definition checks. The common base carries the code, severity, primary location, expected text and enclosing path. cause selects the active detail member: the Schema finding that explains the violation, the original Reader detail when the wire input itself is malformed, or the Codec detail when a builtin rejects a Value it interprets, such as a non-canonical DER INTEGER. The common base owns its bounded path value, so copies retain valid external Tag borrows without self-references.

Note
Report entries are always Schema findings with cause TLV_SCHEMA_CAUSE_SCHEMA.
